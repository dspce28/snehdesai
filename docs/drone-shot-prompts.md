# Drone-shot prompts for the CYL hero

For ChatGPT (Sora / image generation) or Gemini (Veo / Imagen). Generate in this order. Each shot reuses the look of the one before, so they cut together.

**Rules for every shot**
- 16:9 landscape, the highest resolution available (1920×1080 minimum, 4K if offered), 24 fps.
- No text, logos, watermarks, captions or on-screen graphics.
- No music. Mute any audio before sending.
- Send the original MP4/PNG files, not screenshots.

---
